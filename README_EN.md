# claude-notepad

> A sidecar session notepad for Claude Code: never takes over your terminal, never changes how you work — it just remembers the windows you opened today so you can restore them tomorrow.

English | [简体中文](README.md)

## Why

Every day you open a dozen Claude Code windows across different directories. Then you shut down at 6pm, and by tomorrow morning you have no idea what was open or what each one was doing.

Existing tools (e.g. [claude-squad](https://github.com/smtg-ai/claude-squad)) are TUI managers that take over your sessions. claude-notepad goes the other way — **it takes over nothing**:

- **Zero intrusion**: reads the session transcripts Claude Code already writes to disk (`~/.claude/projects/`). No hooks, no config changes, nothing injected.
- **Zero learning cost**: keep using Claude Code exactly as before; restoring uses the native `claude --resume`.
- **Just a notepad**: one small window listing recent sessions, tick and restore, close it and move on.

## Features

- Lists recent Claude Code sessions: time / project directory / what it was doing (from Claude Code's auto-generated session titles)
- Pagination (10 per page)
- Tick multiple sessions and restore at once; "Restore yesterday" brings back every window from yesterday
- Double-click a row to restore that session
- English / 简体中文 UI (follows system language; override with `CLAUDE_NOTEPAD_LANG=zh|en`)

Restore = opens a new Windows Terminal window in the original project directory running `claude --resume <sessionId>`, with the full conversation history intact.

## Usage

Download `claude-notepad.exe` from [Releases](../../releases), or run from source:

```bash
python notepad.py
```

Build the exe yourself:

```bash
pyinstaller --onefile --noconsole --name claude-notepad notepad.py
```

Requirements:

- Windows 10/11 (Python 3.10+ only when running from source)
- `claude` CLI on PATH
- Windows Terminal recommended; falls back to a plain cmd window

## How it works

Claude Code records every session in `~/.claude/projects/<encoded-project-dir>/<sessionId>.jsonl`, which already contains:

| Info | Source |
|---|---|
| Last active time | file mtime |
| Project directory | the `cwd` field inside the record |
| What it was doing | the `ai-title` field (auto-generated by Claude Code), falling back to the first user message |

claude-notepad just reads those and lays them out; restoring calls the native `claude --resume`.

## Known limitations

- Windows you opened but never typed into leave no record (Claude Code writes the file on first interaction)
- Restores conversation history, not terminal window layout
